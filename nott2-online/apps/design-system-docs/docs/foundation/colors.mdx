# Colors

In *Night of the Thirteenth 2*, color is not just decoration. It is the game engine's vocabulary. The palette is intentionally constrained so that when a color speaks, the player instinctively understands what the system is telling them before they read a single word.

All color tokens live in the theme contract (`vars.color.*`). Components reference tokens, never hardcoded values — this means a playset can completely change the visual identity by providing a single new theme.

## The Vocabulary of Color

The game relies on seven distinct semantic "voices." Every application of color must align with these emotional temperatures.

### 1. Red: Pain & Interaction
Blood-red is the brand. It is the color of the Killer, the color of a Strike, and the color of an interactive element waiting to be clicked. There is no separate "danger" color — interaction and danger are inherently linked in a Slasher game.

- **Use for:** Hover states, focus rings, primary actions, strikes earned, characters killed.

| Token | Value | Role |
|---|---|---|
| `color.accent` | `#8a0000` | Primary brand color — borders, fills, decorations |
| `color.accentBright` | `#dc2626` | Hover/active states, error text, focus rings |

### 2. Green: Survival
Green is the color of relief. It confirms that a threat has been neutralized, a weakness has been discovered, or a player is safe and ready. It is a rare color, appearing only when the players earn a victory against the deck.

- **Use for:** Defeated face cards, trophy additions, "Ready" states.

| Token | Value | Role |
|---|---|---|
| `color.success` | `#2d5a2d` | Positive (dark) — borders, glow base |
| `color.successBright` | `#4ade80` | Positive (bright) — text, highlights |

### 3. Amber: Escalation
Amber is caution. Nobody died, but the situation just got worse. The machine is grinding against the players, adding Kings to the deck, or consuming a limited resource like Genre Points.

- **Use for:** Failed number challenges, deck escalation, spent resources.

| Token | Value | Role |
|---|---|---|
| `color.warning` | `#fbbf24` | Caution — warning callouts |

### 4. Orange: Physical Strain
Orange is the body breaking. Amber warns that the situation is worsening; orange says the player *feels* it. It sits between the systemic caution of amber and the lethal finality of red — the moment where effort becomes physical cost. The player hasn't crossed the line yet, but their muscles are screaming.

- **Use for:** EffortBand `overexertion` level, physical strain indicators, high-cost-but-not-lethal consequences.

| Token | Value | Role |
|---|---|---|
| `color.caution` | `#92400e` | Strain base (dark) — borders, background tints |
| `color.cautionBright` | `#fb923c` | Strain bright — text, icon highlights |

:::note Temperature Gradient
The four danger temperatures form a continuous gradient: **green** (safe) → **amber** (system strain) → **orange** (physical strain) → **red** (lethal). Each step raises the emotional temperature without jumping. The EffortBand molecule is the primary consumer of this full gradient.
:::

### 5. Gold: The Attention Beacon
Gold means one thing: *"act here next."* It is the navigational heartbeat of the game. Where red responds to hover and green confirms an outcome, gold guides the player's eye before they've acted.

- **Use for:** Selectable cards on the matt, the drawable threat deck.

| Token | Value | Role |
|---|---|---|
| `color.gold` | `rgb(180, 100, 40)` | Beacon base — resting glow |
| `color.goldBright` | `rgb(220, 160, 60)` | Beacon active — hover states, pulsing highlights |

### 6. Purple: Instruction
Purple is the Game Master's voice pointing a finger. It demands attention without threatening the player. It is narrative intervention.

- **Use for:** "Click the Threat Deck," designating the Prologue active player, aptitude activation.
- **Note:** Purple is UI-only and does not exist in the brand token contract; it is used via hardcoded RGBA in components like StatusCallout.

### 7. Blue: The Machine
Blue is cold, neutral bookkeeping. It represents the mechanical state of the game without any emotional weight.

- **Use for:** Round progress ("2 of 4 players have acted"), shuffling the deck.
- **Note:** Like purple, blue is UI-only and used via hardcoded RGBA.

## The Theme Contract

### Surfaces

The surface hierarchy creates depth through near-imperceptible luminance shifts, keeping the interface recessive so the game pieces pop.

| `color.surface` | `#141414` | Card/panel fill |

### Border Colors

| Token | Value | Role |
|---|---|---|
| `color.border` | `#2a2a2a` | Default dividers, card borders |
| `color.borderSubtle` | `rgba(255,255,255,0.12)` | Faint dividers, outline badges |
| `color.borderActive` | `#8a0000` | Selected card borders, active tabs |

:::note Intentional Hardcoded Hover Tints
Some components use hardcoded low-opacity RGBA values for hover backgrounds (e.g., `rgba(138, 0, 0, 0.05)` on secondary buttons). These are **atmospheric tints** at near-invisible opacity — they derive from brand colors but are too subtle and context-specific to warrant dedicated tokens. See the [Shadows & Glows](/foundation/shadows#hover-tints) page for the full list.
:::

## Usage in Components

Components reference tokens through the Vanilla Extract `vars` contract:

```tsx
import { vars } from '../../tokens/theme.css';

// In a .css.ts file:
const myStyle = style({
  color: vars.color.text,
  backgroundColor: vars.color.surface,
  border: `1px solid ${vars.color.border}`,
});
```
