# PlayerPanel

Phase-aware control surface. Renders different sub-views depending on the current game phase.

## Phase Views

| Phase | Renders | Purpose |
|---|---|---|
| `resolution` | DieSelector pair + DiceResult | Dice rolling interface |
| `fallout` | Strike assignment info | Damage assignment |
| Generic | ActionFooter with phase label | Simple phase advancement |
