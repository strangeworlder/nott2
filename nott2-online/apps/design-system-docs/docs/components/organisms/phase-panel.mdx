# PhasePanel

The director's desk. Structured container with PhaseHeader + scrollable content area. Used for all active-play operational screens.

## Why to Use

PhasePanel provides a consistent operational screen layout. It's the working counterpart to PhaseDisplay — where PhaseDisplay announces, PhasePanel enables action.

## When to Use

- All active-play screens where the player interacts with controls
- Scene setup, conversation & stakes, resolution, fallout

## Anatomy

```
┌── PhasePanel ────────────────────────────┐
│ ┌── PhaseHeader ──────────────────────┐  │
```
