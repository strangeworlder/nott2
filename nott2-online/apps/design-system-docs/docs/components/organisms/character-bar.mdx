# CharacterBar

The playbill at the bottom of the stage. Four characters, always visible, always watching.

<details open>
<summary>Code example</summary>

```tsx
import { CharacterBar } from '@nott2/design-system';

<CharacterBar
  characters={[
    { id: 'Spades', name: 'Alex', strikes: 0, isDead: false, hasAceToken: true, hasActed: false },
    { id: 'Hearts', name: 'Sam', strikes: 2, isDead: false, hasAceToken: true, hasActed: true },
    { id: 'Clubs', name: 'Jordan', strikes: 3, isDead: true },
    { id: 'Diamonds', name: 'Taylor', strikes: 0, isDead: false },
  ]}
  activeCharacterId="Spades"
  genrePoints={{ 'Spades': 2, 'Diamonds': 1 }}
  tableGenrePoints={4}
/>
```
</details>

## Why to Use

The CharacterBar is the persistent emotional register of the game. It shows who is still alive, who is in danger, who has acted this round, and how much luck (genre points) remains at the table. By keeping this organism pinned to the bottom of the viewport, the stakes are always visible.

## When to Use

> **Do**
> - **Always** use `CharacterBar` as the sticky footer across all active game phases (Prologue, Setup, Game Loop).
> - Bind it to the global game state to ensure it accurately reflects the current status.

> **Don't**
> - **Never** use `CharacterBar` for interaction or selection logic. Character selection is handled implicitly by the game rules engine, not by clicking on these cards.

## Key Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `characters` | `CharacterBarCharacter[]` | — | **Required.** Array of up to 4 character data objects. |
| `activeCharacterId` | `string \| null` | — | **Required.** The suit ID of the currently active player (applies the active glow). |
| `genrePoints` | `Record<string, number>` | — | **Required.** A map of `characterId` to individual held Genre Points. |
| `tableGenrePoints` | `number` | — | **Required.** The shared Genre Pool token count, displayed on the far right. |

### CharacterBarCharacter Interface

The object structure expected in the `characters` array prop:

```typescript
export interface CharacterBarCharacter {
  id: string; // Used as the character's Suit
  name: string;
  strikes: 0 | 1 | 2 | 3;
  isDead: boolean;
  hasAceToken?: boolean;
  hasActed?: boolean;
}
```

## Behavior

- **Iteration**: The bar internally maps over the `characters` array, rendering a separate [CharacterCard](/components/molecules/character-card) molecule for each entry.
- **Scrolling**: On narrow screens (mobile), the inner container will allow horizontal scrolling to ensure all character cards are accessible without breaking layout.
- **Genre Pool**: The `tableGenrePoints` is rendered separately from the character cards on the far right edge of the bar.
