# Stack

The spine of every phase screen. A vertical column of moments, each leading inexorably to the next. Like the scenes in a horror film, Stack gives rhythm — a beat here, a beat there, always pressing downward. It is deliberately invisible, serving only to space and order.

<details open>
<summary>Code example</summary>

```tsx
import { Stack } from '@nott2/design-system';

<Stack gap="md">
  <Text variant="h3">Scene Setup</Text>
  <Text>Draw the first card from the Threat Deck.</Text>
</Stack>
```
</details>

## Why to Use

Stack eliminates manual margin management. Without it, developers inevitably reach for one-off `margin-bottom` values or hardcoded pixel gaps — both of which leak outside the spacing token system and break visual consistency across screens. Stack enforces the spacing scale, ensuring that the rhythm of vertical content always comes from the same design vocabulary.

**Never use manual `margin-bottom` between elements. If it's vertical spacing, it's Stack.**

## When to Use

> **Do**
> - Use Stack as the primary vertical layout primitive for any vertical sequence of elements.
> - Use `gap="sm"` for tightly-grouped related content (labels and their fields, icon + description pairings).
> - Use `gap="md"` (the default) for general-purpose layouts — cards, callouts, content sections.
> - Use `gap="lg"` or `gap="xl"` for generous section-level spacing between distinct conceptual groups.

> **Don't**
> - Don't add `margin` directly to child elements to adjust spacing — change the Stack's `gap` instead.
> - Don't nest multiple Stacks just to change the gap for a single child — restructure the content grouping instead.
> - Don't use Stack for horizontal layouts — use [Row](/components/atoms/row) for side-by-side arrangements.

## Key Props

### `gap`
Controls the space between every direct child.

| Value | Token | Approx. px | When to use |
|---|---|---|---|
| `xs` | `vars.space.xs` | 4px | Micro-groupings (e.g., icon + inline label) |
| `sm` | `vars.space.sm` | 8px | Tight content (form fields and their labels) |
| `md` | `vars.space.md` | 16px | **Default.** General content rhythm |
| `lg` | `vars.space.lg` | 24px | Section spacing within a panel |
| `xl` | `vars.space.xl` | 32px | Major section separations |

### `id`
HTML id attribute applied to the root `div`.

| Type | Default | Description |
|---|---|---|
| `string` | `undefined` | Standard HTML id. |

<details>
<summary>Code example</summary>

```tsx
<Stack id="setup-form" gap="md">
  <TextField label="Room Code" value={code} onChange={setCode} />
</Stack>
```
</details>

## Behavior

- Stack renders as a `div` with `display: flex; flex-direction: column` and `gap` set to the token value.
- It imposes no width, padding, or background — it is pure spacing infrastructure.
- The `gap` applies uniformly between **every** direct child. To vary spacing within a Stack, group children in nested Stacks with different gaps.

## Accessibility

- Stack is a generic layout `div` with no ARIA role. It is semantically invisible to screen readers — only its children matter.
- Do not use `id` for ARIA labelling — use it only for scroll targeting or test selection.
