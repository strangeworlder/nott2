# Stack

The spine of every phase screen — a vertical column of moments, each leading inexorably to the next. Stack is deliberately invisible, serving only to space and order.

## Why to Use

Stack provides consistent vertical spacing between children without manual margin management. It uses the spacing token scale to maintain rhythm across the interface.

## When to Use

- **Always** for vertical layouts — never use manual `margin-bottom` between elements.
- Default gap `md` (16px) works for most content.
- Use `lg` gap for generous section spacing, `sm` for tight groupings.

## Key Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `gap` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Space between children |
| `className` | `string` | — | Additional CSS class |
