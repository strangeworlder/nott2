# SelectableTile

A discrete choice laid bare. Unlike a `Toggle` strip which feels like a settings switch, a `SelectableTile` is tactile and independent. It is a die face on the table, a card waiting to be flipped, a module waiting to be activated. When selected, it glows with intent — danger (red), safety (green), or neutral.

<details open>
<summary>Code example</summary>

```tsx
import { SelectableTile } from '@nott2/design-system';

<SelectableTile selected={true} variant="danger" onClick={() => {}}>
  10
</SelectableTile>
```
</details>

## Why to Use

The `SelectableTile` encapsulates the visual logic of a mutually exclusive grid choice. It provides out-of-the-box support for the design system's signature glowing selection states, eliminating the need for manual `box-shadow` or hover CSS.

## When to Use

> **Do**
> - Use in a `Grid` or `Row` when the user must pick exactly one item from a visual matrix (e.g., Die faces, character grid).
> - Use appropriate variants to signal the nature of the choice (`danger` for threats, `default` for safety/activation).

> **Don't**
> - Do not use as a simple binary on/off switch for a single setting; use `Toggle` for that.
> - Do not use as a generic call to action; use `Button`.

## Key Props

Use these props to configure the SelectableTile component.

### selected
Whether the tile is currently active and glowing.

| Type | Default | Description |
|---|---|---|
| `boolean` | `false` | Whether the tile is currently active. |

### variant
The color of the active glow.

| Type | Default | Description |
|---|---|---|
| `'default' \| 'danger' \| 'neutral'` | `'default'` | The color of the active glow. `default` is green, `danger` is red, `neutral` is subtle red. |

### disabled
Standard HTML disabled state.

| Type | Default | Description |
|---|---|---|
| `boolean` | `false` | Disables interaction and dims the tile. |
