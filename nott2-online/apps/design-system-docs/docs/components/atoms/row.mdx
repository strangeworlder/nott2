# Row

Horizontal flex row layout. The counterpart to Stack — arranges children side-by-side with configurable gap, wrapping, and alignment.

## Why to Use

Row ensures consistent horizontal spacing and alignment. It handles flex wrapping gracefully and supports all common alignment patterns.

## When to Use

- Inline button groups
- Badge clusters
- Icon + text pairings
- Any horizontal arrangement of elements

## Key Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `gap` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'sm'` | Space between children |
| `wrap` | `boolean` | `false` | Allow flex wrapping |
| `justify` | `'start' \| 'center' \| 'end' \| 'between'` | `'start'` | Justify content |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'center'` | Align items |
