# Grid

A rigid structure of confinement. Unlike the `Row` or `Stack` which flow and wrap naturally, the `Grid` forces content into a predefined matrix. It is mathematical and unyielding — perfect for arrays of choices, dice faces, or systematic data.

<details open>
<summary>Code example</summary>

```tsx
import { Grid } from '@nott2/design-system';

<Grid columns={4} gap="sm">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
</Grid>
```
</details>

## Why to Use

The `Grid` atom replaces manual CSS grid definitions and inline styles when you need exact, equal-width column layouts. It guarantees consistent structural rhythm aligned with the design system's spacing tokens.

## When to Use

> **Do**
> - Use for strict multi-column layouts like dice selection grids, character grids, or data matrices.
> - Use when items must align perfectly vertically across multiple rows.

> **Don't**
> - Do not use `Grid` when items should natural flow or wrap based on their intrinsic width (use `Row` with the `wrap` prop instead).
> - Do not use for simple vertical stacking (use `Stack`).

## Key Props

Use these props to configure the Grid component.

### columns
The number of equal-width columns in the grid.

| Type | Default | Description |
|---|---|---|
| `1-12` | `1` | The number of equal-width columns. |

### gap
The spacing between items in the grid.

| Type | Default | Description |
|---|---|---|
| `'none' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'sm'` | Spacing between grid items, mapping to design tokens. |
