# Separator

A horizontal rule. A visual breath between content sections.

## Why to Use

Separator replaces raw `<hr>` elements with a themed, consistent divider that uses the `border` token color.

## When to Use

- Between distinct content sections within a card or panel
- Before action footers
- As visual punctuation in long content flows

## Key Props

No props. A single-purpose element.

## Implementation Examples

<ComponentPreview column>
  <Stack gap="md">
