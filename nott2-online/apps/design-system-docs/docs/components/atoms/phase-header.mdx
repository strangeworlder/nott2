# PhaseHeader

Operational screen title component: title + optional subtitle + optional step indicator ("Step 2 of 4"). Used at the top of PhasePanel.

## Why to Use

PhaseHeader provides a consistent header pattern for operational game screens — the screens where players make decisions and interact with controls.

## When to Use

- At the top of every `<PhasePanel>` screen
- **Not** for cinematic moments — use `<PhaseDisplay>` for dramatic, full-bleed announcements

## Key Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | — | Phase/screen title |
| `subtitle` | `string` | — | Optional explanatory subtitle |
| `step` | `number` | — | Current step number |
| `totalSteps` | `number` | — | Total steps (renders "Step X of Y") |

## Implementation Examples

```tsx
<PhaseHeader
  title="Conversation & Stakes"
  subtitle="Discuss what your characters discover and declare your effort."
  step={2}
  totalSteps={4}
/>
```

## Related Components

- **[PhasePanel](/components/organisms/phase-panel)** — The operational screen container (wraps PhaseHeader)
- **[PhaseDisplay](/components/organisms/phase-display)** — Cinematic full-bleed counterpart (NOT for operational screens)

:::important PhaseHeader vs PhaseDisplay
PhaseHeader = operational workspace title (structured, compact). PhaseDisplay = cinematic narration (full-bleed, dramatic). Never use PhaseDisplay for a screen where the player needs to interact with controls.
:::
