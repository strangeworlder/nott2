# CardMatt

The physical playing surface where 3D cards land. The CardMatt acts as a designated zone — a textured, felt-like table segment with a dashed border that grounds the physical game pieces.

<details open>
<summary>Code example</summary>

```tsx
import { CardMatt } from '@nott2/design-system';

<CardMatt 
  title="Threats"
  count={3}
  glow={false}
  ref={mattRef}
/>
```
</details>

## Why to Use

Every card game needs a table. CardMatt provides the visual and technical context for the 3D cards rendered by the `react-ttrpg-cards` physics engine. It serves two purposes:
1. **Visual grounding**: It provides a red velvet textured surface and bounds for the cards.
2. **Technical targeting**: It acts as a ref-forwarding container so the physics engine can measure a specific, tight bounding box (the right 75% of the surface) for card placement, preventing cards from scattering across the entire screen.

## When to Use

> **Do**
> - **Always** use CardMatt as the drop zone for the active game cards (like the Threat Deck cards currently in play).
> - Use the `glow` prop when the game state specifically requires the player to select a card on the matt.

> **Don't**
> - **Never** use CardMatt for UI cards (like the `Card` molecule). It is strictly for diegetic 3D playing cards.
> - Don't use raw `<div>`s to collect cards.

## Anatomy

```
 ┌────────────────────────────────────────────────────────┐
 │                                                        │
 │  T   ┌─ dashed border, velvet texture ──────────────┐  │
 │  I   │                                              │  │
 │  T   │           [Empty Hint]                       │  │
 │  L   │                or                            │  │
 │  E   │           [Count Badge] (top right)          │  │
 │      │                                              │  │
 │      │       [Invisible Target Area (ref)]          │  │
 │      └──────────────────────────────────────────────┘  │
 │                                                        │
 └────────────────────────────────────────────────────────┘
```

1. **Title** — Rotated 90° CCW on the left edge, mimicking casino table printed labels.
2. **Surface** — Red velvet texture with a dashed gold border.
3. **Empty Hint / Count** — Status text indicating either the action to take when empty, or the current card count.
4. **Target Area** — An invisible inner `div` that receives the forwarded `ref` for physics targeting.

## Key Props

### `title`
The label rendered rotated on the left edge of the matt.

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | `'Visible Threats'` | The text identifier for this matt area. |

Status indicators for the cards on the matt.

|---|---|---|---|

### `glow`
A state modifier that changes the border animation to a brighter, faster gold pulse. Used to signal that the player needs to interact with the cards on the matt.

| Prop | Type | Default | Description |
|---|---|---|---|
| `glow` | `boolean` | `false` | When true, applies the selection signal animation. |

### `ref` (Forwarded)
CardMatt forwards its ref directly to an internal, invisible `div` that represents the ideal drop zone for the cards. This inner div is horizontally offset to avoid the title and provides a tighter area for the physics engine to calculate landing positions.

```tsx
const mattRef = useRef<HTMLDivElement>(null);

<CardMatt ref={mattRef} />
```

## Behavior

- The dashed border is static by default to establish the space without drawing excess attention.
- The `glow` prop switches the surface to use `cardMattGlowPulse`, a dramatic box-shadow beacon signalling card selectability.
- Text elements (`title`, `emptyHint`) utilize the standardized `Text` component (`label` variant). The `emptyHint` text is colored gold to prompt action, while the `title` remains muted.
- The `count` utilizes the `Badge` atom (`outline` variant) for a clean, recognizable stamp that is easily scanned.

## Accessibility

- `CardMatt` is a visual and layout container. The 3D cards themselves handle their own accessibility (such as ARIA live regions for screen readers announcing the dealt cards).
- The text inside the matt (`title`, `emptyHint`, `count`) provides visual context but is not interactive.
- All animations respect `prefers-reduced-motion` by disabling the pulse keyframes and setting static fallback borders.
