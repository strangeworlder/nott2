# SceneDossier

The open case file and director's monitor on the table while a scene unfolds. Where `SceneChallengeOverlay` is the jump-cut title card that slams the player into a room, `SceneDossier` is the persistent diegetic stage that keeps the crime-scene photo, suit threat, active spotlight, and target difficulty anchored at the top while the lower stage progresses through the scene's dramatic beats (`'script'` → `'stakes'` → `'aftermath'`).

<SceneDossier

## Why to Use

In a multi-role horror TTRPG, dumping the Active Player's prompt, the Camera Crew's prompt, Escalation rules, Stakes confirmation, and post-roll Deck Changes into a vertical stack of generic `<Card>` containers makes the game feel like a web dashboard rather than a slasher film.

`SceneDossier` solves this through three structural principles:

1. **Persistent Diegetic Anchor:** The crime-scene evidence Polaroid, suit threat heading, active character spotlight, and Target Difficulty remain pinned in the dossier header so players never lose sight of the physical threat after dismissing `SceneChallengeOverlay`.
2. **Side-by-Side Dual-Role Screenplay (`'script'` mode):** Everyone at the table sees both the **Director (Active Player)** prompt and the **Camera Crew (The Table)** prompt side-by-side across a vertical crimson gradient divider, while `<ScriptSparks>` drawers are gated to each player's active role.
3. **Progressive Beat-by-Beat Stage (`'script'` → `'stakes'` → `'aftermath'`):** Instead of scrolling down a long form, the lower stage swaps cleanly between framing the scene (`'script'`), committing to the Overexertion sacrifice (`'stakes'`), and resolving the post-roll Fate & Fallout ledger (`'aftermath'`).

## When to Use

> **Do**
> - Use `SceneDossier` as the primary centerpiece in `ConversationStakesScreen` (Step 2/4) and `FalloutScreen` (Step 4/4).
> - Gate `directorSparks` to the Active Player and `cameraSparks` to the Camera Crew in multiplayer rooms so each player only sees their own improvisation drawer.
> - Use the ambient `onEscalate` / `escalated` props for *"Something's Not Right..."* rather than rendering a separate rules `<Card>`.

> **Don't**
> - Do not pair `SceneDossier` with a duplicate `<DifficultyBadge>` on the same screen — the dossier header already owns the Target Difficulty readout.
> - Do not stack multiple `SceneDossier` instances on a single screen; swap `mode` (`'script'` | `'stakes'` | `'aftermath'`) as the player advances through beats.

In Beat 1 of Step 2 (and Beat 1 of Step 4), the stage splits into two columns: the **Director (Active Player)** on the left in italic `Playfair Display`, and the **Camera Crew (The Table)** on the right in `Inter`, separated by a vertical gradient divider. ### 2. Stakes Beat (`mode="stakes"`) & Escalation Stamp (`escalated={true}`)

When the table clicks **Set the Stakes →**, the dossier header stays anchored while the lower stage transitions to `mode="stakes"`, focusing on the Overexertion question and Act-scaled stakes guidance. If the Camera Crew has triggered *"Something's Not Right..."*, the left-edge bleed thickens to `4px` and a tilted crimson stamp brands the dossier.

## Anatomy

```
┌────────────────────────────────────────────────────────────────────────────┐
┃ ┌────────┐  ♠ POWER (PHYSICAL THREAT)                        │   TARGET    │  headerBar
┃ │ PHOTO  │  ♠ Alex   [The Jock] [The Protective]             │     6       │  (photoFrame + headerMeta
┃ └────────┘                                                   │  Rank = 6   │   + difficultyBlock)
├────────────────────────────────────────────────────────────────────────────┤
┃ [!] “Something’s not right...” (Escalate Once)   [Need a Spark? — Words]   │  escalationStrip
├────────────────────────────────────────────────────────────────────────────┤
┃ 🎬 DIRECTOR — ACTIVE PLAYER       │  🎥 CAMERA CREW — THE TABLE            │  scriptGrid (mode="script")
┃ “Something cold and vice-like     │  What did they kick loose in the       │  (roleColumn + scriptDivider
┃  snatches your ankle...”          │  struggle, and what sound retreats?    │   + roleColumn)
┃ [Need a Spark? — 9 Words]         │  [Need a Spark? — 9 Sensory + Focus]   │
└════════════════════════════════════════════════════════════════════════════┘
  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
  Inset bottom wound + external crimson glow pool
```

1. **Root (`styles.dossierRecipe`)** — Implements the **Bleeding Component** stack: a 3px pulsing crimson left-edge bleed (`4px` when `escalated`), a 1px inset crimson bottom wound with external glow, and a left-to-right directional wash.
2. **Dossier Header (`styles.headerBar`)** — Houses the tilted Polaroid `photoFrame` (with `vhs-grain.png` texture overlay), `headerMeta` (suit theme, active character badge, optional Prologue `archetypes`), a vertical gradient `headerDivider`, and `difficultyBlock`.
3. **Escalation Strip (`styles.escalationStrip`)** — Renders either the interactive *"Something's not right..."* trigger button (`styles.escalationTriggerBtn`) or the angled crimson `escalationStamp` when `escalated={true}`, alongside optional `escalationSparks`.
4. **Sacrifice Banner (`styles.sacrificeBanner`)** — Shown when `sacrificeTriggered={true}` (Post-Roll Effort 3+), reminding the table that the agreed Overexertion sacrifice happens now.
5. **Dual-Role Script Grid (`styles.scriptGrid`)** — Shown when `mode="script"`. Two equal columns separated by a 1px vertical gradient `scriptDivider` (collapsing to a horizontal gradient divider on viewports `≤640px`).
6. **Single-Stage Container (`styles.singleStage`)** — Shown when `mode="stakes"` or `mode="aftermath"`, providing a clean header bar with a `Back to Scene` button (`onBackToScene`) and dedicated stage content.

## Key Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `mode` | `'script' \| 'stakes' \| 'aftermath'` | `'script'` | Controls which dramatic beat is rendered in the dossier stage. |
| `imageSrc` | `string` | — | Optional URL for the Polaroid crime-scene photo in the header. |
| `suitIcon` | `IconName` | — | Suit or threat icon displayed next to `suitTheme`. |
| `suitTheme` | `string` | — | Uppercase suit theme or encounter label in the header. |
| `activeCharacterName` | `string` | — | Spotlight character's name in the header. |
| `activeCharacterSuit` | `IconName` | — | Suit icon for the spotlight character. |
| `archetypes` | `readonly string[]` | — | Optional Prologue archetype tags rendered next to the character name. |
| `difficulty` | `number \| null` | — | Target difficulty number in the right-hand header readout. |
| `difficultyBreakdown` | `string` | — | Formula caption under `difficulty` (e.g., `"Trophy (4) + 2 = 6"`). |
| `escalated` | `boolean` | `false` | Intensifies the dossier's bleed/glow and replaces the trigger button with the crimson Escalation stamp. |
| `onEscalate` | `() => void` | — | Callback fired when the *"Something's not right..."* button is clicked. |
| `escalationSparks` | `ReactNode` | — | Optional inline `<ScriptSparks>` rendered in the escalation strip. |
| `sacrificeTriggered` | `boolean` | `false` | Renders the heated Overexertion sacrifice reminder strip above the stage. |
| `directorPrompt` | `string` | — | Active Player prompt rendered in the left column (`mode="script"`). |
| `directorSparks` | `ReactNode` | — | Slot for the Director's role-gated `<ScriptSparks>` (`mode="script"`). |
| `cameraPrompt` | `string` | — | Camera Crew prompt rendered in the right column (`mode="script"`). |
| `cameraSparks` | `ReactNode` | — | Slot for the Camera Crew's role-gated `<ScriptSparks>` (`mode="script"`). |
| `stakesQuestion` | `string` | `'If you end up pushing yourself...'` | Core Overexertion question (`mode="stakes"`). |
| `stakesGuidance` | `string` | — | Act-scaled stakes guidance (`mode="stakes"`). |
| `stakesSparks` | `ReactNode` | — | Slot for `<ScriptSparks>` (`mode="stakes"`). |
| `fateItems` | `readonly SceneDossierFateItem[]` | `[]` | Compact 1-line fate & deck outcomes (`mode="aftermath"`). |
| `weaknessSlot` | `ReactNode` | — | Optional inline `<WeaknessTracker>` (`mode="aftermath"`). |
| `strikesSlot` | `ReactNode` | — | Optional Blood Price strike assignment controls (`mode="aftermath"`). |
| `genrePointSlot` | `ReactNode` | — | Optional inline Genre Point award controls (`mode="aftermath"`). |
| `onBackToScene` | `() => void` | — | Optional callback to return to Beat 1 (`mode="stakes"` or `"aftermath"`). |

## Visual Identity Alignment

| Principle | How SceneDossier Implements It |
|---|---|
| **Dark Canvas, Luminous Actors** | Uses the **Bleeding Component** stack (left-edge bleed + inset bottom wound + directional wash) so the dossier radiates crimson heat instead of floating on drop shadows. |
| **Physical Imperfection** | The crime-scene Polaroid tilts at `-1.5deg`, and the Escalation stamp uses `clip-path: polygon(...)` with a `-1.5deg` rotation. |
| **Semantic Heat** | Escalating from a 3s subtle crimson bleed to a 2s 4px bright crimson bleed when escalated, with orange thermal accents on Overexertion stakes and sacrifice banners. |
| **Diegetic Texture** | Composites `vhs-grain.png` with `mix-blend-mode: overlay` over the desaturated crime-scene Polaroid in the header. |
| **Cinematic Pacing** | Replaces vertical scrolling feeds with `200ms ease-out` beat transitions (`'script'` → `'stakes'` → `'aftermath'`). |

## Accessibility

- **Landmark semantics:** Renders as a `<section>` with `aria-label="Scene Dossier: {suitTheme}"` and exposes `aria-label="Target Difficulty {difficulty}"` on the difficulty readout.
- **Live status announcements:** Both the Escalation stamp (`role="status"`) and the Sacrifice Triggered banner (`role="status"`) announce state changes to assistive technology.
- **Reduced motion:** All entry animations, stamp slams, and left-edge bleed pulses disable cleanly under `@media (prefers-reduced-motion: reduce)`.
