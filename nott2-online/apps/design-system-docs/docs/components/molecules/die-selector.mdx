# DieSelector

Tactile die selection. A grid of clickable faces for d4 (1–4) or d10 (0–9).

<details open>
<summary>Code example</summary>

```tsx
import { DieSelector } from '@nott2/design-system';

<DieSelector 
  sides={10} 
  color="red" 
  value={4} 
  onChange={(val) => console.log(val)} 
  label="Threat Die (d10)" 
/>
```
</details>

## Why to Use

Rolling dice is the moment the horror has been building toward — the determination of fate. This component makes die selection tactile and deliberate. Clicking a face is a choice, not a roll.

Internally, it utilizes the `Grid` and `SelectableTile` atoms to enforce a strict layout and standard selection interactions.

## When to Use

> **Do**
> - Use as a manual fallback during the Resolution phase when 3D dice are unavailable.
> - Use `color="red"` for the Threat Die (d10) to reinforce danger.
> - Use `color="white"` for the Effort Die (d4).

> **Don't**
> - Do not use this for generic numerical input (like selecting a number of players). It is strictly for die roll inputs.
> - Do not try to override the width or grid layout; it is strictly controlled by its internal `Grid` atom.

## Key Props

Use these props to configure the DieSelector component.

### sides
Determines the die type and number of faces.

| Type | Default | Description |
|---|---|---|
| `4 \| 10` | — | **Required.** `4` generates faces 1–4. `10` generates faces 0–9. |

### onChange
Callback fired when a face is clicked.

| Type | Default | Description |
|---|---|---|
| `(val: number) => void` | — | **Required.** Selection handler. |

| Type | Default | Description |
|---|---|---|
