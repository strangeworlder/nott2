# TrophyIndicator

The power level of evil. The trophy top card sets the baseline for every Face Card encounter — it is the Killer's current strength. This indicator should feel like a status effect on the monster: amber-toned and ominous, always present, always climbing.

<details open>
<summary>Code example</summary>

```tsx
import { TrophyIndicator } from '@nott2/design-system';

<TrophyIndicator suit="Spades" rank={5} />
```
</details>

## Why to Use

TrophyIndicator provides a compact, at-a-glance summary of the current trophy top card — the card that determines the Killer's base difficulty. The amber color palette separates it from the red (danger) and green (success) systems, establishing a neutral-but-ominous "monster status" aesthetic.

## When to Use

> **Do**
> - Use in the `PhaseHeader` or `GameBoard` sidebar to persistently display the current trophy top card.
> - Pass the `suit` and `rank` directly from the game engine's `deck.trophyTop` state.

> **Don't**
> - Do not use as a generic card display. Use `PlayingCard` for showing actual cards.
> - Do not confuse this with `StrikeIndicator` (player health) or `WeaknessTracker` (weakness discovery). This is specifically about the Killer's power level.

## Anatomy

```
 ┌──────────────┐
 │  🏆 Trophy   │    ← trophyLabel (nano, amber, icon + text)
 │     5 ♠      │    ← trophyCard (display font, rank + suit icon)
 │   Rank 5     │    ← trophyRank (nano, amber, muted)
 └──────────────┘
```

1. **Root** (`trophyRoot`) — Inline flex column with amber border (`rgba(234,179,8,0.3)`) and faint amber background tint (`rgba(234,179,8,0.04)`).
2. **Label** (`trophyLabel`) — "🏆 Trophy" in nano uppercase. Uses `emoji_events` Material Symbol (16px) and amber text.
3. **Card display** (`trophyCard`) — The rank label + suit icon in display font at `h3` size. This is the hero element. Rank labels map: 1→A, 11→J, 12→Q, 13→K, else the number.
4. **Rank line** (`trophyRank`) — "Rank N" in nano uppercase, amber, at 70% opacity.

## Key Props

Use these props to configure the TrophyIndicator component.

### suit
The suit of the trophy top card.

| Type | Default | Description |
|---|---|---|
| `string` | — | **Required.** One of `'Spades'`, `'Hearts'`, `'Clubs'`, `'Diamonds'`. Determines the suit icon via `suitToIconName()`. |

### rank
The numeric rank of the trophy top card.

| Type | Default | Description |
|---|---|---|
| `number` | — | **Required.** Range 1–13. Face card labels are auto-mapped: 1→A, 11→J, 12→Q, 13→K. |

## Behavior

- **Rank label mapping**: The component auto-maps numeric ranks to face card labels using an internal `RANK_LABELS` lookup: 1→"A", 11→"J", 12→"Q", 13→"K". All other numbers display as-is.
- **Suit icon resolution**: The `suitToIconName()` utility maps suit strings to the design system's custom SVG suit icons (`spades`, `hearts`, `clubs`, `diamonds`).
- **Amber identity**: The entire component uses a consistent amber/gold palette — the same warmth as the `DiceResult` total number and `DieChip` modified state — to establish "the Killer's power" as its own visual lane, separate from player actions (red) and success (green).

## Accessibility

- Uses `role="status"` with `aria-label` announcing the full card identity (e.g., "Trophy top: 5 of Spades, rank 5").
- The card display (rank + suit icon) is marked `aria-hidden="true"` — the `aria-label` on the root provides the complete semantic information.
