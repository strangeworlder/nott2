# ScriptSparks

The table's read-only 9-word improvisation drawer. *"They should never be the answer, only the starting point for the answer."* When a prompt asks the Active Player (Director) or the Camera Crew to describe a scene, escalate the danger, or name a sacrifice, `ScriptSparks` folds open to reveal **9 evocative words** drawn uniformly with zero overlap from a multi-axis thematic pool — alongside optional Act-specific **"Focus the Camera"** questions for the Camera Crew.

<details open>
<summary>Code example</summary>

```tsx
import { ScriptSparks } from '@nott2/design-system';
import { getCombinedFragmentPool } from '@nott2/game-engine';

const fragmentPool = getCombinedFragmentPool({
  suit: 'Spades',
  act: 2,
  rank: 6,
  playsetId: 'default',
});

// Active Player (Director) word bank
<ScriptSparks
  words={fragmentPool.activePlayerWords}
  triggerLabel="Need a Spark? — 9 Director Words"
/>

// Camera Crew sensory bank + official Focus the Camera questions
<ScriptSparks
  words={fragmentPool.cameraCrewWords}
  questions={fragmentPool.cameraQuestions}
  triggerLabel="Need a Spark? — 9 Sensory Words & Camera Questions"
/>
```
</details>

## Why to Use

Pre-written full sentences fight the scene the table has already imagined and make the game feel like a multiple-choice quiz.

`ScriptSparks` is designed around three facilitation principles:

1. **Read-only inspiration, never a choice button:** Nothing inside the open drawer is selectable or saved to game state, and it never completes a game phase. It exists purely as mental fuel for what the player says aloud.
2. **9 Evocative Words per Role:**
   - **Active Player (`activePlayerWords`):** Mixes abstract thematic concepts and visceral nouns/verbs (*"Meat"*, *"Wound"*, *"Electronics"*, *"Clanking"*, *"Leverage"*, *"Paranoia"*) merged across Universal/Playset + Suit + Act + Rank Group axes.
   - **Camera Crew (`cameraCrewWords` + `cameraQuestions`):** Pairs 9 sensory/atmospheric words (*"Dripping"*, *"Copper"*, *"Flicker"*, *"Rot"*, *"Echo"*, *"Shadow"*) with the Act's official **"Focus the Camera"** questions from `NotT_2.md`.
3. **Zero-Overlap Uniform Shuffle:** Clicking **Shuffle Words** deals 9 fresh words from the combined pool while excluding the 9 words just shown.

## When to Use

> **Do**
> - Slot `ScriptSparks` into [`SceneDossier`](/components/molecules/scene-dossier) (`directorSparks`, `cameraSparks`, `escalationSparks`, `stakesSparks`).
> - Gate `directorSparks` to the Active Player and `cameraSparks` to the Camera Crew in multiplayer rooms so each player only sees their own role's word bank.
> - Pass `words={fragmentPool.activePlayerWords}` for the Director and `words={fragmentPool.cameraCrewWords}` + `questions={fragmentPool.cameraQuestions}` for the Camera Crew.

> **Don't**
> - Do not use `ScriptSparks` as a selection control or form input.
> - Do not pass tiny pools; use `getCombinedFragmentPool()` from `@nott2/game-engine` (60+ words per role).

By default, `ScriptSparks` stays folded into a compact, dashed-border trigger button (`"Need a Spark?"`) with a crimson `lightbulb` icon.

```
State 2: Revealed Drawer (isOpen)
┌────────────────────────────────────────────────────────────────────────────┐
│ 9 EVOCATIVE WORDS TO SPARK YOUR NARRATION:   [refresh] Shuffle  [^] Close  │  trayHeader
├────────────────────────────────────────────────────────────────────────────┤
│ [Meat] [Wound] [Electronics] [Clanking] [Leverage] [Paranoia] [Alibi] ...  │  wordsGrid (wordChip × 9)
├────────────────────────────────────────────────────────────────────────────┤
│ FOCUS THE CAMERA (ASK ONE):                                                │  questionsSection (optional)
│ “What does it look like?”  “What does it smell like?”  “Is it pitch black?”│  questionChip × N
└────────────────────────────────────────────────────────────────────────────┘
```

## Key Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `words` | `readonly string[]` | — | Pool of evocative words (9 drawn at a time with zero overlap). |
| `sparks` | `readonly string[]` | — | Alias for `words`. |
| `questions` | `readonly string[]` | — | Optional Act-specific *"Focus the Camera"* questions for the Camera Crew. |
| `questionsLabel` | `string` | `'Focus the Camera (ask one):'` | Header above the optional camera questions section. |
| `triggerLabel` | `string` | `'Need a Spark?'` | Label on the collapsed disclosure button. |
| `trayHint` | `string` | `'9 evocative words to spark your narration (grab one or two):'` | Uppercase micro-hint in the tray header. |
| `reloadLabel` | `string` | `'Shuffle Words'` | Label on the shuffle button inside the tray header. |
| `onReload` | `() => void` | — | Optional callback fired when the user clicks **Shuffle Words**. |
| `defaultOpen` | `boolean` | `false` | Whether the tray starts expanded on mount. |
| `id` | `string` | — | Optional HTML `id` attribute. |
