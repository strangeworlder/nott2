# DiceResult

The autopsy report. Clinical `d10 + d4 = Total` layout. 

After the dice have settled, this component presents the clinical breakdown of what happened. It is the most-viewed UI state in the game. Its typography is precise and unambiguous — no drama here, just the truth of the numbers.

<details open>
<summary>Code example</summary>

```tsx
import { DiceResult } from '@nott2/design-system';

<DiceResult d10={7} d4={3} />
```
</details>

## Why to Use

`DiceResult` provides a standardized, mathematical layout for the core resolution mechanic. It leverages `subgrid` to ensure the d10, operator, d4, and Total columns always align perfectly across the horizontal axis, regardless of whether a modifier is present.

## When to Use

> **Do**
> - Use as the primary display immediately after a player has committed their effort and threat rolls.
> - Provide the `modifier` and `originalD4` props when a player's Aptitude alters the roll.

> **Don't**
> - Do not use this component to declare success or failure. This component is just the math; use `ResultBanner` for the verdict.

## Key Props

Use these props to configure the DiceResult component.

### d10
The threat die result.

| Type | Default | Description |
|---|---|---|
| `number` | — | **Required.** The base threat value (usually 0-9). |

### d4
The effort die result (or final modified effort value).

| Type | Default | Description |
|---|---|---|
| `number` | — | **Required.** The effort value. If modified, this should be the post-modification value. |

### modifier & originalD4
Used when an Aptitude modifies the d4 effort roll. Both must be provided together to trigger the modified visual state (red text and struck-through original).

| Type | Default | Description |
|---|---|---|
| `{ value: -1 \| 1, label: string }` | — | The applied modifier object. |
| `number` | — | The original d4 value before modification. |
